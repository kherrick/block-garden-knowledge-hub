🌱 Block Garden

A 3D sandbox exploration, building, and farming game engine

v1.0 Sandbox Procedural Worlds Native Web Component

🎮 Live Playable Game

Explore Block Garden directly below via the native <block-garden> custom element, dynamically loaded and rendered securely inside ShadowClaw.

🌿 Block Garden Live Sandbox

✨ Engine Features

🌍 Procedural Worlds

Uniquely seeded 3D voxel terrain with simplex noise heightmaps, dynamic biomes, underground caves, and celestial sky clouds.

🌾 Farming & Cultivation

Multi-stage crop growth cycles, tilled soil hydration, seed planting, harvesting, and botanical resource management.

⛏️ Mining & Resources

Dig through surface soil, bedrock, coal seams, iron veins, and precious gold deposits to build intricate structures.

🔌 Modular ES6 API

Dynamic runtime module loading, procedural drawing effects, game state bookmarklets, and custom scripting.

⌨️ Quick Controls

🚶 Movement & Camera

  • W A S D — Move forward / left / back / right
  • Space — Jump / Ascend
  • Shift — Descend
  • K — Toggle Flight Mode
  • Arrow Keys — Rotate Camera

🛠️ World Interaction

  • Left Click (Hold) — Break Block
  • Right Click / Enter — Place Block
  • ~ / ` — Cycle Block Type
  • E / I — Open Inventory
  • M — Toggle Hotbar
